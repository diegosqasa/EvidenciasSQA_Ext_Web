Política de Privacidad - Evidencias SQA

Extensión Web Evidencias SQA • Última actualización: 05 de septiembre de 2026

SIN ANALYTICS • SIN PUBLICIDAD • SIN TERCEROS Toda la información procesada por Evidencias SQA permanece en el dispositivo del usuario y únicamente se comunica con la aplicación local Evidencias SQA mediante 127.0.0.1.

1. Finalidad de la extensión

Evidencias SQA es una herramienta diseñada para capturar, organizar y gestionar evidencias de pruebas de software.

Permite a los analistas de calidad (QA) capturar contenido visual, agregar anotaciones esenciales y asociar cada evidencia a Historias de Usuario (HU) y Casos de Prueba (CP), facilitando la documentación, trazabilidad y generación de reportes de aseguramiento de calidad.

La extensión funciona únicamente cuando el usuario inicia una captura de manera explícita.

2. Datos que se capturan

Dato Uso
Imagen capturada (PNG) Generar evidencia visual solicitada por el usuario
URL de la página Metadatos de la evidencia
Título de la página Metadatos de la evidencia
Fecha y hora de captura Trazabilidad QA
Navegador y versión Metadatos de la evidencia
Sistema operativo Metadatos de la evidencia

La extensión no recopila:

  • Historial de navegación
  • Contraseñas
  • Cookies
  • Información financiera
  • Información médica
  • Pulsaciones de teclado
  • Analítica de uso
  • Telemetría de terceros
  • Publicidad o seguimiento de usuarios

3. Dónde se almacenan los datos

Almacén Contenido Retención
chrome.storage.local Token temporal de autenticación y configuración básica Temporal
IndexedDB (SQAOfflineDB) Capturas pendientes cuando la aplicación de escritorio no está disponible Hasta sincronización exitosa
Memoria temporal del Service Worker Datos utilizados durante una captura activa Temporal

Las capturas no se almacenan en servidores externos.

4. Comunicación con la aplicación de escritorio

La extensión se comunica únicamente con la aplicación Evidencias SQA instalada en el mismo equipo mediante: 

http://127.0.0.1:3000

La comunicación se utiliza exclusivamente para:

  • Transferir capturas realizadas por el usuario.
  • Sincronizar capturas pendientes.
  • Consultar el estado de la aplicación local.
  • Obtener tokens temporales de autenticación.

No se utilizan cookies ni se envían datos a servicios externos.

5. Permisos utilizados

Permiso Uso
activeTab Capturar el contenido visible de la pestaña activa cuando el usuario inicia una captura.
tabs Obtener URL, título y metadatos de la pestaña capturada.
scripting Ejecutar temporalmente la lógica necesaria para capturas de página completa y selección de área.
clipboardWrite Copiar capturas al portapapeles únicamente bajo acción explícita del usuario.
storage Guardar configuraciones y tokens temporales necesarios para el funcionamiento de la extensión.
unlimitedStorage Permitir almacenamiento temporal de capturas pendientes para sincronización offline.
<all_urls> Permitir capturas en cualquier sitio web, intranet, ambiente de pruebas, localhost o documento PDF solicitado explícitamente por el usuario.

6. Captura de documentos PDF y archivos locales

La extensión puede capturar documentos PDF abiertos por el usuario.

Cuando el usuario habilita expresamente el acceso a URLs de archivo (file://) desde el navegador, la extensión puede procesar dichos documentos para generar la evidencia solicitada.

No existe acceso automático a archivos locales fuera de una acción explícita iniciada por el usuario.

7. Uso de los datos

Los datos procesados por la extensión se utilizan exclusivamente para:

  • Generar evidencias visuales.
  • Asociar evidencias a Historias de Usuario y Casos de Prueba.
  • Facilitar la documentación de pruebas.
  • Generar reportes de QA.
  • Sincronizar capturas con la aplicación Evidencias SQA.

Los datos no se utilizan para publicidad, marketing, analítica o perfilado de usuarios.

8. Compartición de datos

Evidencias SQA no vende, comparte ni transfiere datos de usuarios a terceros.

Toda la información permanece:

  • En el dispositivo del usuario.
  • En la extensión.
  • En la aplicación local Evidencias SQA.

9. Seguridad

La comunicación entre la extensión y la aplicación Evidencias SQA se realiza exclusivamente mediante localhost: 

127.0.0.1

Los tokens utilizados para la comunicación son temporales y se renuevan automáticamente.

La extensión no acepta conexiones desde sitios externos ni carga código remoto.

10. Eliminación de datos

Al desinstalar la extensión:

  • Se eliminan los datos almacenados en chrome.storage.local.
  • Se elimina la base de datos IndexedDB asociada a la extensión.

Las evidencias ya almacenadas en la aplicación de escritorio son gestionadas conforme a la política de dicha aplicación.

Privacy Disclosure

Evidencias SQA no recopila datos para publicidad, analítica ni seguimiento de usuarios.

Las capturas se generan únicamente bajo acción explícita del usuario y permanecen almacenadas localmente en el dispositivo.

La extensión se comunica exclusivamente con la aplicación Evidencias SQA ejecutándose localmente mediante 127.0.0.1.

No se comparten ni venden datos de usuarios a terceros.

Single Purpose

Evidencias SQA ayuda a equipos de aseguramiento de calidad (QA) a capturar, organizar y documentar evidencias visuales de pruebas, vinculándolas a Historias de Usuario y Casos de Prueba para generar reportes estandarizados y mejorar la trazabilidad de las validaciones realizadas.
